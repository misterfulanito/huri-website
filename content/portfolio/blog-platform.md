# Blog Platform

A developer-friendly blogging platform optimized for technical content and long-form writing.

## Features

- **MDX Support**: Write in Markdown with React components
- **Syntax Highlighting**: Beautiful code blocks with Prism
- **SEO Optimized**: Meta tags, sitemap, and Open Graph
- **RSS Feed**: Let readers subscribe to updates
- **Reading Time**: Estimated time for each article
- **Social Sharing**: One-click sharing to social platforms

## Technical Highlights

- Static site generation for maximum performance
- Contentlayer for type-safe content management
- Automatic sitemap and RSS generation
- Dark mode support with system preference detection

# E-commerce Platform

A complete e-commerce solution built with modern technologies for performance and scalability.

## Features

- **Product Catalog**: Categories, search, and filtering
- **Shopping Cart**: Persistent cart with quantity management
- **Secure Checkout**: Stripe integration for payments
- **User Accounts**: Order history and saved addresses
- **Admin Dashboard**: Inventory, orders, and analytics

## Technical Implementation

- Server-side rendering with Next.js for SEO
- Type-safe database queries with Prisma
- Secure payment processing with Stripe
- Image optimization with Next.js Image component

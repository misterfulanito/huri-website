# Weather Dashboard

An elegant weather application that provides comprehensive weather information with beautiful visualizations.

## Features

- **7-Day Forecast**: Detailed daily and hourly predictions
- **Interactive Maps**: Radar, temperature, and precipitation layers
- **Location Search**: Find weather for any city worldwide
- **Weather Alerts**: Stay informed about severe weather
- **Historical Data**: View past weather patterns

## Technical Highlights

- Multiple API integration for data accuracy
- Responsive charts with Chart.js
- Custom map overlays with Mapbox
- Geolocation support for automatic local weather
